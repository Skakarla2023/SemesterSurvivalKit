# Cousins of the compiler

- In the process of converting high level language to low level language, several modules work together with the compiler.
- These are called cousins of compiler.
- They are:
  - Preprocessor
  - Assembler
  - Interpreter
  - Linker
  - Loader
 
## Preprocessor

- Responsible for processing the code before it is passed to the compiler.
- It perfoms operations like:
  1. Macro expanmsion
  2. File inclusion
  3. Conditional Compilation

eg: #include,#define in C++

## Assembler

- An assembler is a program that translates assembly language(low level but human readable) into machine code.
- Each assembly instruction corresponds to one machine instruction.
- It geneates one object file as output.

## Interpreter

- An interpreter translates and executes the program line by line.

- Unlike a compiler (which translates the whole program at once), the interpreter executes statements immediately.

- Slower than a compiler but useful for debugging.

Example: Python interpreter, JavaScript engine.

## Linker

- A linker combines the multiple obj files generated by the assembler into single executable file.
- Makes sure all function calls and variables are connected correctly.

## Loader

- Loader is a part of the Operating System.
- It loads the program into main memory for execution.
