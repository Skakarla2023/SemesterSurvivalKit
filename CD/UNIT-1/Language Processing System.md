# 🌐 Introduction to Language Processing System

- When we write a program (like in C, Java, Python), the computer cannot directly understand our high-level language (English-like instructions).
- The computer only understands machine code (0s and 1s).

- we need a Language Processing System → it’s like a translator that converts our human-friendly program into machine-friendly instructions.

### Steps inside Language Processing System 🛠

1. Editor: Where you write the code(C or Java)
3. Preprocessor: Cleans the code before execution(removes comments,includes header files)
4. Compiler/Assembler/Interpreter
    - Compiler: converts the whole code at once
    - Interpreter: converts line by line
    - Assembler: converts assembly code into machine code
5. Linker: Joins your program with extra libraries needed.
6. Loader: loads the program into memory for execution
7. Execution: executes the program
