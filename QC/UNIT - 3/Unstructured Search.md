# Unstructured Search

- Unstructured search problem is searching algorithm in quantum computing, where we are supposed to search for an item, from a larger collection of items,that are not arranged in any specific order.
- In quantum computing, Grover's algorithm helps us solve this problem faster than classical search methods.

**Eg:**

- Suppose we have 1000 unsorted boxes, and only one box contains a gold coin.
- We need to find the box containing the gold coin.
- In classical computing, we may need to check each box one by one. It takes approximately O(N) operations in the worst case.
- In quantum computing, Grover's Algorithm can find the required box in approximately O(√N) operations.
