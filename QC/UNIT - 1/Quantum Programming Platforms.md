# Quantum Programming Platforms

- Quantum Programming Platforms refers to the software environment and tools that are used to write, test, develop, simulate and execute quantum programs.
- They help programmers develop applications using the principles of quantum computing.
- They provide programming language, libraries, simulators and access to quantum computers.
- They help developers create quantum circuits and perform quantum operations.

Eg: Just as Python is used to write normal computer program, Qiskit or Cirq are used to write quantum programs.

**Qubit** 

- It is the basic unit of information storage in quantum computing.
- It can have values of either 0 or 1, and linear combination of both(a property known as superposition).

**Quantum Gate**

- Quantum gates are operations used to change the state of qubits.
- They are similar to logic gates in classical computers.
- Examples are: Hadamard gate, pauli-X gate, etc


**Quantum Circuit**

- A series of quantum gates are applied on qubits to perform a particular task.

**Quantum Simulator**

- Quantum simulator is a software, that mimics the behavior of a quantum computer.
- It allows developers to simulate and test quantum programs without actually using quantum computer.

**Quantum Hardware**

- It refers to the physical quantum computer that executes quantum programs using real qubits.


## Major Quantum Programming Platforms

### Qiskit

Qiskit is an open-source quantum computing software development framework developed by IBM.
- It uses the Python programming language.
- It helps create and execute quantum circuits.
- It provides quantum simulators.
- It allows users to access IBM quantum computers.

### Cirq

Cirq is an open-source quantum programming framework developed by Google.
- It uses Python.
- It is used to create and simulate quantum circuits.
- It focuses on controlling and experimenting with quantum hardware.

### Microsoft Q#

Q# (Q Sharp) is a quantum programming language developed by Microsoft.
- It is specially designed for quantum computing.
- It allows programmers to write quantum algorithms.
- It works with the Microsoft Quantum Development Kit.

### Amazon Bracket

Amazon Braket is a cloud-based quantum computing service provided by Amazon Web Services (AWS).
- It provides access to different quantum hardware providers.
- It allows users to design and test quantum circuits.
- It provides simulators for testing quantum programs.

### ProjectQ

ProjectQ is an open-source quantum computing software framework developed at ETH Zurich.
- It uses Python.
- It helps write quantum programs.
