|Topic| Classsical computing | Quantum Computing |
|-----|----|------|
| Basis of Computing |Largescale multipurpose computers based on classical physics.|High speed computers based on quantum mechanics.|
| Information storage| Bit based information storage using voltage/charge. | Qubit based information storage using electron spin or polarization.|
| Bit Values| Bit values having 0 or 1 can have a single value at any time.| Qubit values can be 0 or 1, or a linear combination of both( a property called as superposition)|
| Number of possible states | Number of possible states is 2, either 0 or 1. | Number of possible states is infinite, as many combinations of 0 and 1 exist. |
| Output| Deterministic|Probabilistic|
| Gates used for processing| Logic gates(AND, OR, NOT, CNOT etc) | Quantum gates(X,Y,Z, CNOT etc) |
| Operations| Operations use Boolean algebra | Operation use linear algebra and and are represented by unitary matrices.|
| Circuit Implementation| Circuit implemented using macroscopic technologies. | Circuit implemented using microscopic technologies. |
| Data Processing| Data processing is carried out of logic gates in seuquential order. | Data procesing is carried out by quantum logic at parallel instances.|
