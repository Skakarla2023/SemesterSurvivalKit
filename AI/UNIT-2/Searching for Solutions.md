### Searching for Solutions in AI

- In Aritificial Intelligence, searching refers to the process of navigating from start state to goal state.
- This process involves transitioning through different states.

#### **search**:
It is a step by step process to solve a problem.
####  **Search Space**:
The set of possible solutions.
####  **Start state**: 
This is the state where the agent begins the search.
####  **Goal state test**:
In this it checks the current state and returns whether the goal state is reached or not.
####  **Actions**:
Available actions to the agent.
####  **Transition Model**:
The transitional model explains the details of each process.
####  **Search tree**:
A search tree is a tree representation of a search problem.
