### Agents in AI

- In AI, agents are software programs that perceive the environment and take a series of decisions to achieve some specific goals.

### Types of Agents

1. Simple Reflex agent
2. Model based agent
3. Goal based agent


#### Simple Reflex Agent

- This type of agent takes decisions or performs task only based on the present input.
- They do not have past memory.
- This type of model is suitable for predictable environment.

eg: vaccum cleaner(it cleans only when it observes dirt)

#### Model based Agent

- This type of agent has internal memory of the past events, it is suitable for partially visible environments.
- The internal memory of agents have internal memory which helps them in taking decisions when they cannot see the environment directly.
- Uses both current input and internal memory while making decisions.

eg: self driving car( if it sees a man across the road, it remembers the truck that came across it stopped, and it has to stop now after seeing a man on the road)

#### Goal based Agent

- This type of agents chooses actions based on whether they help it achieve the goal.
- This agent plans a sequence of actions that helps it achieve the goal.
- It may try different paths to find the best one.
