# 🧠 Search Algorithms

## Uninformed Search

- Uninformed search algorithms operate without any additional knowledge about the problem domain beyond the problem's definition. They explore the search space systematically but "blindly," meaning they do not use any information to guide them towards the goal.

- Examples of uninformed search
  1. BFS
  2. DFS
  3. Uniform cost search
  4. Iterative deepening DFS
  5. Bidirectional search
  6. Depth limited search
 
  
## Informed Search

- Informed Search algorithms use additional domain specific knowledge known as heuristic, that guides them towards the goal.

- Heuristics are the funtions that estimate the cost from current node to the goal node.

- examples of informed search are:
  1. Best first Search
  2. A* Algorithm
