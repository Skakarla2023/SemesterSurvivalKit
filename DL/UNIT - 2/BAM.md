# BAM

- Bidirectional Associative Memory (BAM) is a type of recurrent neural network used to store and recall pairs of associated patterns.
- So, unlike a normal associative memory that mainly works in one direction, BAM works in both directions.
- It was developed by Cosco in the year 1988.
- It performs forward as well as backward search.


**eg:**

For example:

English word ↔ Hindi word
```
CAT ↔ बिल्ली
```
Later, if we give:
```
CAT
```
BAM recalls:
```
बिल्ली
```
And if we give:
```
बिल्ली
```
BAM recalls:
```
CAT
```
