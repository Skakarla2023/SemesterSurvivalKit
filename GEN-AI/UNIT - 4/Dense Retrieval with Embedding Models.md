# Dense Retrieval with Embedding Models

Dense Retrieval is a method of retrieving documents by converting queries and documents into numerical vectors called embeddings and finding vectors that are close to each other.

Instead of matching exact words, it finds documents based on their meaning.

The vectors are usually generated using an embedding model.


#### Embedding Model

- An embedding model is a machine learning model that converts text into a list of numbers.
- These numbers represent the semantic meaning of the text.
- Although the sentences use different words, their meanings are similar. Therefore, their embeddings may be close to each other in vector space.

Eg:

```
"I love dogs."
"Dogs are my favourite animals."
```
