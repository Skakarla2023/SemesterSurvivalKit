# Overview of Semantic Search and RAG

- Semantic search is a search technique that understands the meaning and intent of the user rather than searching only for the exact matching words.
- It tries to understand what the user actually wants and finds results with similar meaning.
- It uses NLP(Natural Language Processing) and embedding models to find and understand the meaning of words.
