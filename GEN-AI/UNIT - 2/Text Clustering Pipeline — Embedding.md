# Text Clustering Pipeline — Embedding

Text Clustering is the process of grouping similar text documents or sentences together without giving predefined labels.

Embedding is the process of converting text into numerical vectors so that a computer can understand its meaning.

In simple words, text clustering groups sentences with similar meanings into the same group using embeddings.
