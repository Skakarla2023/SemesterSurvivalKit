# Model Selection

- Model selection is the process of choosing the most suitable machine learning or NLP model for a given task based on the task requirements, data, accuracy, cost and performance.
- Different models perform differently on different tasks. So, we must select a model that gives good results for our problem.
- For example, if we want to classify movie reviews into Positive and Negative categories, we may choose BERT because it understands the context and meaning of words.
- But if we want to classify a large amount of text without labelled training data, a zero-shot classification model may be more suitable.
