# LangChain

- Langchain is a open source framework used to develop applications powered by Large Language models.
- There are 6 components in langchain:
  - Models
  - prompts
  - chains
  - memory
  - indexes
  - agents
 
### Models

- These are the interfaces through which you interact with the AI models.
- The major application of NLP is chatbot.
