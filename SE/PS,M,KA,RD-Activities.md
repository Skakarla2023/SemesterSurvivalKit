# FrameWork Activities in Software Engineering

- Framework activities provide the basic framework of tasks that every software project goes through.
- These activities help us understand the problem, analyse it and then finally design an appropriate software system to solve it.
- Follwing are the Framework activities in SE:
  - Problem Solving Activity
  - Modelling Activity
  - Knowledge Acquisition activity
  - Rationale Driven Activity


## Problem Solving Activity

### What it is:

- This activity is about identifying the **real problem** that we need to solve by building a software and thinking for possible solutions.

### Why we need it:

- Because software is not just writing code, it is meant to solve problems.

### Steps involved:

- Understand the problem.
- Proposing possible solutions.
- Choosing the feasible or the best solution among them.

## Modelling Activity

### What it is:

- In this we design a model of the system by using diagrams,flowcharts, ER diagrams or UML diagrams, so that the developers can visualize the system effectively.

### Why we need it:

- Humans understand more through diagrams rather than raw text.

### Types of Models:

- Structural Models
- Behavioural Models

## Knowledge Acquisition activity

### What it is:

- This activity involves gathering information from clients, users, domain experts and readind documents to fully understand the system.
  
### Why we need it:

- Developers do not have complete idea of the domain(library,hospital), so they collect information from the respective people for better understanding of the problem.

### Steps involved:

- Interviews with clients
- Questionnaire

## Rationale Driven Activity

### What it is:

- In this activity we define the **logic behind reasoning**, i.e., instead of saying "we did this", we say "why we did this".
  
### Why we need it:

- Helps future developers understand logic behind choices and avoid repeating mistakes.
  
### Steps involved:

- Documenting why a design was chosen.
- Recoring alternatives why we didn't chose them or why we rejected them.
