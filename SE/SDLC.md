# SDLC (Software Development Life Cycle)

1. Analyse
2. Design
3. Testing
4. Implementation
### 5. Deployment

- Once the software is developed, making it availabe to the user is called deployment.

### 6. Maintenance

- Once the software is released, issues or problems may appear, so new features may be needed.
- So new changes and improvements are needed to be made time-to-time.
- It includes measures such as checking for bugs, adding new improvements, making changes to prevent any issues in future.


### Process: 

set of activities used to develop a asoftware.

### Project

Actual work done to create a product using the process.

### Project
