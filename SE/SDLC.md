# SDLC (Software Development Life Cycle)

### 1. Planning

- This is the first stage in software development.
- IUnderstand what software will be made and why.
- prepare a project plan.


### 2. Analysis

- Gather information from customers and users
- It involves the following steps:
  - Understand the problem
  - Analyse the problem
  - Formulate the solution

### 3. Design

- Divide the larger module into smaller submodules and design them individually and them combine them to form the larger module.

### 4. Implementation

- programmers will write code based on the design.
- Frontend and backend is developed.

### 5. Testing

- This process involves testing the functionalities of the software.
- Checking whether it gives the correc output fot the correct input.
- To find for any errors or bugs.


### 6. Deployment

- Once the software is developed, making it availabe to the user is called deployment.

### 7. Maintenance

- Once the software is released, issues or problems may appear, so new features may be needed.
- So new changes and improvements are needed to be made time-to-time.
- It includes measures such as checking for bugs, adding new improvements, making changes to prevent any issues in future.


### Process: 

set of activities used to develop a asoftware.

### Project

Actual work done to create a product using the process.

### Project

Final software that is delivered to the user.
