# Software Development Models

Process model is a framework that describes the activities, tasks, and milestones at each stage of software development project that leads to high qualitgy software.

Life Cycle Models:

- Waterfall Model
- Incremental process Model
  - Incremental Model
  - RAD Model
- Evolutionary Process Model
  - Sprial Model
  - Prototyping Model
 

## Waterfall Model:

<img width="693" height="375" alt="image" src="https://github.com/user-attachments/assets/4568b791-7dac-41a3-bbe0-74f901122335" />

### Uses:

1. Easy to understand, easy to use.
2. Works well when quality is more important than cost or schedule.
3. Milestones are well understood.

### Drawbacks:

1. All projects cannot follow linear process.
2. A working version of the project will not be avilable until late in the project life-span .
3. Customer must have Patience.

## Incremental SDLC Model:

1. Combines elements of waterfall model in an iterative fashion.
2. A partial implementation of the system is built.
3. Then slowly add functoinalities.
4. Each subsequent release of the system will be added as a new functionality to the system.
5. User requirements are prioritized.

### Diadvantages

1. requires good planning and model.
2. Total cost of the system is higher.


## prototyping Model:

<img width="612" height="649" alt="image" src="https://github.com/user-attachments/assets/4f81fd15-c7c8-4d48-8a38-2477220b90a1" />

1. A prototype is a partially developed product that enables customers and developers to examine whether the propsed system is suitable or approppriate for the finished product.
2. This model is suggestes when requirements are changing.
3. Customers are actively involved in development.
4. Errors can be decided much earlier.

### Disadvantages:

1. Client inolvement is more.
2. SLow process.
3. Cost of implementation is more.
4. Frequently modig=fying the system disturbs the rhythm of development.

## Sprial Model

1. It combines the iterative nature of prototyping model and systematic aspects of waterfall model.
2. The process is defined as a sprial rather than sequence of activities.
3. Each spiral represents a phase in the process.

<img width="838" height="537" alt="image" src="https://github.com/user-attachments/assets/5906d805-be4a-4b1d-b935-e919ff860c8a" />

1. first sprial: conceptual developemnt
2. second spiral: system development
3. third sprial: system enhancement
4. fourth spiral: system maintains

## V Model:

<img width="760" height="663" alt="image" src="https://github.com/user-attachments/assets/d0e99d78-a446-4eec-87bd-1d5bdd7554d7" />

1. V-model means verification and validation model.
2. It is a sequential path of execution of processes.
3. Each phase must be completed before the startng of next phase.
4. Testing of the product is done in parallel with the corresponding phase of development.



## RAD Model:

1. An incremental process model that emphasizes short development cycle.
2. **High speed** implemenation of waterfall model.
3. Integration from the very beginning solves a lot of integration issues.
4. Changing requirements can be accommodated.

### Disadvantages:

1. Requires highly skilled designers.
2. Cost of modeling is high.
