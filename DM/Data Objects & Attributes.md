# Data Objects

- A data set will be made of data objects.
- A Data object is a real world entity.
- These are represented using attributes.

# Data Attributes

- The Attributes are used to represent the characteristics of the data.
- Types of attributes are:
  - Nominal attribute
  - ordinal attribute
  - binary attribute
  - numeric attribute


## Nominal Attribute

 - The values of these attributes are simply names.
 - They do not have any meaningful info.
 - In data mining, these are used for classification of data.
 - eg marital_status, hair_color

## Binary Attributes

- These are the nominal attributes with only 2 state-0,1.
- there are 2 types of binary attributes:
  - Symmetric binary attributes
  - Asymmetric binary attributes

### Symmetric binary attribute

- Both values are equally important.

eg:gender

### Asymmetric binary attribute

- One value is more important than other.

eg:disease test:(yes/no)


## Ordinal Attributes 

- The values of these attributes have meaningful information with ranking.

eg:size-{small,medium,large}


## Numeric Attributes 

- The values of these attributes are numbers or quantity.

### Interval 

- Measured on a scale of equal units.
eg: temperature 

### Ratio

- Values have order, difference and a true zero.
eg: salary
