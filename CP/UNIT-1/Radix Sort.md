# 🍁 Radix Sort

- It is a non-comparision based sorting Algorithm.
- It sorts the numbers by processing individual numbers from **Least significant digit(LSD)** to **Most significant digit(MSD)**.

##  Algorithm:

1. Start from the rightmost digit of the number.
2. Sort them by using any sorting algorithm(counting sort).
3. Now move to the next digit(10's place).
4. Repeat the same process until you are done with all the digits of the greatest number.
5. Now all the numbers are sorted.
