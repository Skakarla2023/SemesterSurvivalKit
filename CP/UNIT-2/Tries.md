# Tries

- Tries are tree like data structures used to store strings or words.
- Each node in a trie represents a character.
- It is used to solve problems involving prefixes or searching words quickly.
- It is also called **radix tree** or **prefix tree**.
- There are 2 types of tries:
  - Standard tries
  - Compressed tries
 
## Standard Tries

- A standard trie for a set of strings is an ordered tree such that:
- Every node except the root note is labelled with a character.
